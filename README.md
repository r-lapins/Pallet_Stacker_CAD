# Pallet_Stacker_CAD

https://youtu.be/SEa4gPryweE

**Autodesk Inventor iLogic / VBA.NET**

The scripts are intended for preview purposes only. Upon request, the author can demonstrate their functionality directly within Autodesk Inventor.

## aa_Pallet_BTP_template.iam
A template file in which the main script should be executed.

## rule_pallet_progressBar.vbs
This script stacks window slats with spacers in the same way a robot would place them on a pallet.  
It requires a properly prepared Excel file as the data source.

- generates nearly 200 full pallets in under 5 minutes  
- automates the pallet assembly creation process  
- reflects real-world robotic stacking logic  

## rule_all_pallet_progressbar.vbs
Creates a consolidated `.iam` assembly based on pallets generated by `rule_pallet_progressBar.vbs`.
